# UI панелі, редактора й Mini App

Загальні заборони — в [AGENTS.md](../../AGENTS.md); тут лише правила теми.

- Вставлене користувачем/пропозицією має бути видимим у справжньому редакторі:
  колір, позначка чернетки, перехід до рядка; одного toast недостатньо.
  Не зберігайте пропозиції автоматично й не перехоплюйте фокус після іншого переходу.
- «Рядок N» веде до справжнього поля; check/save мають однакову нумерацію,
  включно з вимкненими непорожніми рядками; застарілі помилки не ведуть до іншого рядка.
- Один Save угорі біля пошуку/додавання; новий рядок отримує текст пошуку.
  Лічильник увімкненого лише у вкладці, без дублів. Перевірка чернетки видима.
- Зберігайте чернетки й позицію прокрутки. Час — місцевий, циферблат замість сітки.
  Вибірки шукають reference розміченого (навіть порожній), інакше final/raw;
  типовий порядок часовий, «спершу нерозмічені» окремий; сортуйте до пагінації.
- Конфлікти навчання показують альтернативу й джерела; «Дозволити» їх не усуває.
  Правильний еталон не змінюють заради універсального правила.
