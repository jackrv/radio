# Radio 345 — правила для агентів

Локальне розпізнавання радіоефіру на Mac; продовжуйте наявний проєкт.
Спілкування — російською; документація, UI й повідомлення — українською;
commit messages — англійською. Актуальну конфігурацію перевіряйте в коді.

## Початок і завершення роботи

- Перевірте гілку й робоче дерево; зберігайте сторонні незакомічені зміни.
- Прочитайте [ідеї](docs/ideas.md), перегляньте [покажчик звітів](docs/reports/README.md)
  та відкрийте лише матеріали своєї теми. Вікі: [docs/README.md](docs/README.md).
  [Зроблене](docs/ideas-done.md) і [старіші звіти](docs/reports/archive.md) — лише за темою.
- Економія контексту: читайте вибірково (grep, діапазон рядків, `head`), не цілі
  великі файли; обмежуйте вивід команд і тестів (`-q`, `| tail`); логи/БД/JSON
  не виводьте повністю. Відповідь — коротко, без переказу вже сказаного.
  Субагентів запускайте лише на прохання власника.
- Після суттєвого етапу збережіть звіт і посилання в покажчику: дата, commit,
  dirty state, докази, обмеження, перевірки, залишок. Відрізняйте вимірювання
  від припущень. Не накопичуйте історію й лічильники тестів у цьому файлі.
- Ідеї/рішення ведіть у docs/ideas.md: відкрите, відхилене з причиною, зроблене.
  Не повертайте відхилене без нових доказів. `.wishlist` — приватні побажання
  власника; сам запис не доручає виконання. Не публікуйте його чи приватні приклади.
- Commit/push і перезапуск живих служб — лише в погодженому обсязі.

## Дані й безпека

- Не публікуйте .env, dictionaries.txt, БД, логи, аудіо, діагностику, backups,
  `.local-*`. У коді тестів/документації — лише синтетичні тексти й ідентифікатори.
- Тести SQLite — тільки тимчасові БД; перед записом у живу БД — backup у `.local-backups/`.
- Не видаляйте активні WAL/SHM та `.radio345.lock`: це flock, не файловий прапорець.
- Не робіть сторонній open/close активних SQLite/WAL/SHM у процесі, що використовує
  SQLite: це скидає POSIX-lock інших потоків. Права змінюйте metadata-операціями.
  SQLite context manager не закриває connection — закривайте явно.
  [Причина](docs/reports/2026-11-20-sqlite-lock-fix.md), [перевірка](docs/reports/2026-11-21-sqlite-stability.md).
- Разові дозволи видалення архіву/Telegram не поширюються на нові записи чи діапазони.

## Розпізнавання й експерименти

- Пріоритет: «без правок» → пропущене мовлення → WER; окремо перевіряйте
  хибний текст на noise/notification/room. Raw зберігайте незмінним.
- Без beam_size та заміни чисел «найближчим дозволеним». Словникові блоки й
  підтверджені номери — лише за [погодженими умовами](docs/reports/2026-11-21-dictionary-blocks.md).
- Не вмикайте енергетичний відсів чи загальну заміну «прийом + слово» за припущенням;
  дослідження цілого обороту відкладено в docs/ideas.md.
- Tiny донавчена експериментально, **не ввімкнена**: зросли вигадки на немовленні.
  Нове навчання/важкі прогони самостійно не запускати; optimizer resume відсутній.
  [Пілот і обмеження](docs/reports/2026-11-21-tiny-finetuning-pilot.md).
- Не запускайте MLX ASR/навчання поруч із живою моделлю. CLI-прогін: штатно
  `start_radio345.py --receiver-stop`, після завершення/помилки `--receiver-start`;
  використовуйте model slot і паузи між довгими тестами. Панельна черга керує цим сама.
- Holdout не навчає правила/ваги; рецепт обирайте за validation, не відкритим test.
  Порівнюйте на однакових записах через tools.analysis compare.

## Вимоги до UI й поведінки

- Вставлене користувачем/пропозицією має бути видимим у справжньому редакторі:
  колір, позначка чернетки, перехід до рядка; одного toast недостатньо.
  Не зберігайте пропозиції автоматично й не перехоплюйте фокус після іншого переходу.
- «Рядок N» веде до справжнього поля; check/save мають однакову нумерацію,
  включно з вимкненими непорожніми рядками; застарілі помилки не ведуть до іншого рядка.
- Один Save угорі біля пошуку/додавання; новий рядок отримує текст пошуку.
  Лічильник увімкненого лише у вкладці, без дублів. Перевірка чернетки видима.
- Зберігайте чернетки й позицію прокрутки. Час — місцевий, циферблат замість сітки.
  Вибірки шукають reference розміченого (навіть порожній), інакше final/raw;
  типовий порядок часовий, «спершу нерозмічені» окремий; сортуйте до пагінації.
- Конфлікти навчання показують альтернативу й джерела; «Дозволити» їх не усуває.
  Правильний еталон не змінюють заради універсального правила.
- Gap не доводить сон Mac: класифікуйте за станом потоку ДО розриву;
  paused/listening не приховує наступний active-gap.
- Немовлення відкликається через транзакційний outbox із 20 с undo, без HTTP у review
  й backfill старих міток. skipped_revision не дорівнює applied_revision.
- TTL low_rms — 1 година від захоплення, лише без reference/deferred;
  прогноз і prune спільні, WAV видаляється після commit.

## Інструменти й перевірки

- Readonly аналіз без зупинки: `.venv/bin/python -m tools.analysis summary`;
  errors/conditions/callsigns/records/checks/runs/compare/queue — [довідка](docs/lab.md).
  Архів: RecordingStore(config.RECORDINGS_DIR); API аналізу: services/error_analysis.py.
- Текстові зміни: tools/text_replay; ASR: tools/asr_lab. Реальний UI-сценарій:
  `node tools/check_panel_ui.cjs`; перевірка парсера не замінює API check → save → read.
- Тести: `.venv/bin/python -m pytest -q`, `node --test tests/*.cjs`, `git diff --check`.
  Обирайте перевірки за зміною; явно зазначайте недоступні MLX/PortAudio/браузерні прогони.
- Код читайте спершу через claudeSearch: для `.py`/`.js`
  `outline <файл>` → `method <файл> Class::name`; цілий файл — лише коли потрібен.
  Відсутність у графі не доводить невикористання — перевіряйте `grep`.
- claudeSearch: `bash claudeSearch/cs.sh raw <текст>` / `sql <таблиця>`; граф JS і Python:
  `graph usages|callers|methods|files <ім’я>`, `outline <файл>`, `method <файл> Class::name`
  (маршрути — `graph files "GET /api/…"`). Граф — підказка, не AST. `.claudeignore` обов’язковий.
  [Налаштування й обмеження](docs/reports/2026-11-21-claudesearch-setup.md).

Деталі й історія — у тематичних звітах та [архіві старої пам’ятки](docs/agent-reference-2026-11-21.md).
