# Продовження досліджень Radio 345

Попередній великий handoff описував експериментальний стан 15.11.2026,
старі черги розмітки й попередню модель. Він не є описом чинного приймача.
Історичний текст доступний у Git до коміту очищення; приватні звіти й результати
в `.local-experiments/` збережені, але не публікуються.

Актуальні правила й обмеження: [ASR_TEMPLATES.md](ASR_TEMPLATES.md).
Еталони, лабораторія й відтворення порівнянь: [RECORDINGS.md](RECORDINGS.md).
Часові вимірювання: [DIAGNOSTICS.md](DIAGNOSTICS.md).

Не запускайте Whisper/Qwen паралельно з робочим лаунчером на 16 ГБ RAM.
Спочатку збережіть однакові ID, еталони, параметри й версії для парного порівняння.
Не вважайте накопичені правки навчанням ваг моделі. Нові числа якості публікуйте
разом із розміром корпусу, стадією конвеєра та незалежною відкладеною вибіркою.
