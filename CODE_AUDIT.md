# Аудит використання коду Radio 345

Перевірено Python AST: імпорти, визначення, звернення до імен/атрибутів; додатково
виконано пошук посилань у коді, тестах, CLI, HTML/JS і workflow Pages. Це
консервативний статичний аудит, а не доказ відсутності зовнішніх користувачів API.

## Безпечне прибирання, виконане зараз

- `radio.py`: прибрано невикористаний `import queue`.
- `core/audio_debug.py`: прибрано невикористаний `from pathlib import Path`.

## Кандидати на окреме видалення чи спрощення

| Місце | Що виявлено | Умова безпечної зміни |
| --- | --- | --- |
| `config.py: FUZZY_CORRECTION_SCORE` | Немає звернень у робочому коді | Можна видалити; залишено в цьому коміті як кандидат конфігураційної сумісності |
| `services/event_store.py: apply_learned_corrections()` | Стара корекція цілих фраз; поточна фабрика використовує `apply_verified_word_rules()` | Спочатку погодити відмову від старого Python API й відповідних тестів |
| SQLite `corrections` | Застаріла таблиця для попереднього механізму; нове навчання використовує `word_corrections`/`word_correction_votes` | Потрібна явна міграція та рішення щодо історичних баз; не видаляти таблицю лише через відсутність нових записів |
| `miniapp/styles.css` | Немає поточних посилань на `.item-card`, `.item-icon`, `.chevron`, `.card-copy`, `.role`, `.inline-warning`, `.mini-indicator` | Видалити відповідні правила й залежні медіаправила, після чого перевірити всі екрани на телефоні |
| `miniapp/styles.css` | Початкові стилі частково перекриті компактними правилами в кінці файлу | Об’єднати селектори зі збереженням каскаду та мобільних breakpoint; потрібна візуальна перевірка |
| `__pycache__/`, `.pytest_cache/`, `*.pyc` | Автоматично відновлювані локальні кеші | Можна видаляти за зупинених тестів/служб; вони не входять до Git |

Кандидати з таблиці не видалені автоматично. Тести старої корекції потрібні доти,
доки зберігається відповідний API; їх не можна просто вважати зайвими.

## Що не є невикористаним кодом

- `api/bootstrap_admin.py`, `manage_database.py`, `diagnose_radio345.py`,
  `start_radio345.py` — CLI-точки входу; внутрішній імпорт не обов’язковий.
- `Callsigns.__init__()` і `callsigns.py __main__` — ручна перевірка словника без
  мікрофона. Робочий шлях використовує `from_lines()`, але CLI також корисний.
- `core/audio_debug.py` — обмежений запис за `RADIO_DEBUG_AUDIO=1`, а не постійний шлях.
- `services/telegram_pending.py`, offset і прапорці стану — потрібні для відновлення,
  навіть коли зараз їхні таблиці порожні.
- Всі JS, зазначені в `miniapp/index.html`, включені до Pages workflow і перевіряються тестом.
- `__init__.py`, тести без прямих викликів, обробники подій, callback-функції та
  контекстні менеджери не можна видаляти за простим пошуком назви.
- `.local-backups/`, старі локальні SQLite, `radio*.log`, `debug_audio/` та карантин
  Telegram можуть містити потрібні приватні дані. Вони не входять до Git, але
  відсутність посилань у Python не робить їх безпечними кандидатами на видалення.

Російські форми слів у словниках чисел, аліасах, чорному списку та тестових
радіофразах збережені навмисно: це вхідні дані розпізнавання, а не мова інтерфейсу.
Їх переклад змінив би поведінку й міг би погіршити розпізнавання.
