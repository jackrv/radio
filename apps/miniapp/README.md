# Radio 345 Mini App

Статичний HTML/CSS/JS без збирання. Публікується `.github/workflows/miniapp-pages.yml`
на GitHub Pages і працює з локальним FastAPI через HTTPS-тунель ngrok.

- **Головна** — стан приймача, свій режим сповіщень, пауза (адміністратор).
- **Виправлення** — пошук фраз, аудіо, редактор із підказками оформлення.

Кожен запит перевіряє підпис Telegram `initData` і права в SQLite; роль на
клієнті лише визначає вигляд кнопок. Словники, навчання й користувачі — лише в
локальній панелі.

```bash
node --test tests/miniapp.test.cjs
```

Ролі, правки, синхронізація копій і видалення: [Telegram і Mini App](../docs/telegram.md).
