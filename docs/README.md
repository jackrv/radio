## Головні правила

- **Нічого робочого в Git:** `.env`, `dictionaries.txt`, `events.db`, журнали, копії,
  аудіо, діагностика й каталоги `.local-*` приватні. У прикладах — лише вигадані назви.
- **Числа не вгадуються:** номер ніколи не замінюється «найближчим» дозволеним.
- **Важкі прогони моделей — лише при зупиненому приймачі** (`--receiver-stop`):
  на Mac із 16 ГБ два Whisper одночасно не вміщаються.
- **Робочу конфігурацію змінюємо лише після вимірювання** на розмічених записах.
