# 📱 API вузла для застосунків

[← Вікі](README.md) · [iPhone](iphone-radio.md)

HTTP на порту 8346, лише Tailscale і пристрої облікового запису власника (інакше 403).
Версія контракту: **1**. Кожна відповідь JSON/помилка має заголовок `X-Radio345-Api`.

| Шлях | Відповідь |
| --- | --- |
| `GET /version` | `{"api", "supported", "features"}`; не залежить від версії клієнта |
| `GET /live.mp3`, `/live-clean.mp3` | безперервний MP3: усе мовлення / без сигналів |
| `GET /stream.mp3` | відібрані фрази (на Pi поки порожньо) |
| `GET /events?after=ID` | стан вузла й фрази після `ID` |
| `GET /clip/ID.mp3` | одна фраза |
| `WS /transmit` | PCM16 моно на рацію; 403 — вимкнено, 409 — зайнято |

## Правила сумісності

- Клієнт передає свою версію: `?api=1` або `X-Radio345-Api: 1`. Без неї — версія 1 (чинний iOS-застосунок).
- Непідтримувана версія → **426** і JSON `unsupported_api`: показати «Оновіть застосунок».
- Нові необов'язкові поля й `features` — без нової версії; клієнт ігнорує невідоме.
- Несумісна зміна: версія +1, попередня лишається в `supported`, доки не оновлено застосунки.
- Немає `/version` (404) — старий вузол, версія 1.

Застосунок тримає два незалежні джерела: ефір і PTT — з вузла Pi; тексти й архів — звідти, де вони є.
