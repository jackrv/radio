# 🎧 Аудіоархів і розмітка

[← Вікі](README.md)

Кожен оброблений сегмент зберігається в `.local-data/recordings/` (WAV + метрики). Розмітка в панелі (**Аудіоархів**) дає еталони:
за ними перевіряються моделі, фільтри й шаблони. Еталон мовлення стає текстом пов’язаної події, підпису в Telegram і навчання.

## Як розмічати

Прослухайте запис, оберіть тип, для мовлення введіть **саме почуте**.

| Тип | Коли |
| --- | --- |
| 🗣 **Мовлення** | є слова; сигнал разом із мовленням — теж сюди |
| ❓ **Нерозбірливо** | частину не розібрати; не входить у WER |
| 📻 **Шум ефіру** | шипіння чи тріск рації |
| 🔔 **Сигнал** | звук сповіщення без мовлення |
| ⌨️ **Кімната / клавіатура** | звуки приміщення |

Шум, сигнал і кімната зберігаються одним натисканням; 15 с можна скасувати. Надіслана фраза з такою міткою відкликається в Telegram
(є 20 с на скасування; [подробиці](telegram.md#видалення-в-усіх)).

**Оформлення** (однаково в архіві й Mini App):

- цифри групами, як вимовили: «42 42», «0 22»; команда з цифрами — ВЕЛИКИМИ;
- позивний з великої й номером, групи через кому: «Береза 56, я Клен 15, ЗЛИВА 42 42, посилку отримав, прийом»;
- сталий зворот — без ком усередині; «з», а не «с»; апостроф не пропускати;
- кілька передач — через « / »; слово «прийом» саме по собі межею не є; тоді ролі не позначайте;
- кома між парами прибирається лише в точному коді доби запису.

**Ролі** — табличка «Кому | Від» праворуч від типу. Підставляються самі: позивний після «я» — «Від», єдиний перед ним — «Кому»; без «я» —
лише для двох позивних (перший «Кому»). «Клен 15, посилку отримав» — він «Від»; «Клен 15, прийнято, прийом» — він «Кому». Не вгадуйте з контексту.

Під полем — підказки: **оформлення** (усі разом — «Виправити оформлення»), **«Можливо, …?»** (схоже на назву чи код доби, лише кнопкою),
**ⓘ** — номера немає у словнику («＋ У словник»). Зберегти можна будь-який текст; автоправок при збереженні немає. Маркер слова під час
відтворення — **приблизний** орієнтир.

## Клавіші

| Клавіша | Дія |
| --- | --- |
| Пробіл | грати / пауза |
| 1–5 | тип (2, 3, 5 — одразу зберегти) |
| ⌘Z / Ctrl+Z | скасувати швидку розмітку (15 с) |
| Enter / ⌘+Enter | до тексту / зберегти |
| J/K, ↓/↑ · → / ← | інший запис · інший із відтворенням |
| R / Esc | з початку / вийти з поля (Esc застосовує правки оформлення) |
| ] / [ | швидше / повільніше (0,75× … 2×) |

Поки в панелі звучить запис, приймач закриває мікрофон, щоб не записати колонки (перемикач 🎙️ у шапці).

## Що показати

| Вид | Що |
| --- | --- |
| **Ефір** | знайдено позивний чи створено подію |
| **Інше мовлення** | Whisper щось почув, позивного немає |
| **Шум, сигнали й короткі** | відсіяне програмою |
| **Розмічені** | за часом розмітки, останні першими |
| **Правки з Mini App · Надіслано в Telegram · Усі** | перегляд |
| **Перевірити:** хибний текст, пропущене мовлення, без ролей, нерозбірливі | де помиляється програма або розмітка неповна |
| **Очікують / Записано під час тестів** | розпізнано пізніше, без подій і Telegram |

У перших трьох — лише нерозмічене. Порядок: «нові» або «сумнівні першими» (Whisper найменш упевнений). **Пошук** у шапці: початок ID, «№82»
або шматок тексту з урахуванням фільтрів. Правка з Mini App стає еталоном, якщо змінено не лише регістр чи пунктуацію; розмітку з панелі не переписує.

## Зберігання

- Нерозмічені тихі (`low_rms`) — **до 1 години**; решта нерозмічених — до 7 днів і в межах **5 ГіБ** (першим видаляється відсіяне, ефір — останнім).
- **Розмічені й ті, що очікують розпізнавання, не видаляються.**
- Це **не суцільний запис**: що VAD не почав, не зберігається. Прогноз очищення — **Система → Дані й копії**.

Параметри: `RECORD_AUDIO`, `RECORDINGS_RETENTION_DAYS`, `RECORDINGS_LOW_RMS_RETENTION_SECONDS`, `RECORDINGS_MAX_BYTES`.

## Метрики

Головні — **«Без правок»** (текст збігся з еталоном слово в слово) і **«Пропущено»** (мовлення без тексту); поруч помилка слів до й після
обробки, номери, адресат. **WER** — лише для «Мовлення», без регістру й пунктуації; порожня розшифровка мовлення — пропуск усіх слів.
Хибний текст на шумі рахується окремо. У записі: `raw_text` — Whisper, `filtered_text` — після фільтрів, `final_text` — підсумок.
