# 📚 Словники й фільтри тексту

[← Вікі](README.md)

Панель (**Розпізнавання**), діє **без перезапуску** за кілька секунд. Рядок із `#` не діє; застаріла версія від другої вкладки відхиляється.

## Словники

Позивні, команди й список Telegram (`/watch`); формат — [install.md](install.md#формат-словників). Порожній словник позивних не зберігається.

`злива 4242` і `злива 42 42` **без двокрапки** — один код. `злива: 42 42` — список окремих номерів `42`. Група до 9 цифр сумарно.
Якщо почуто половину однозначного коду ABAB, повтор відновлюється: `злива 42` → `ЗЛИВА 42 42`; `злива 43` не стає `42 42`. Не відновлюється,
якщо короткий код теж дозволено, далі є інша цифрова група або назва збігається з позивним.

### Словник бере участь у виправленні тексту

За точною назвою команди, повною довжиною коду й хоча б однією незміненою групою відновлюється **єдиний** допустимий варіант:
`грім 023` → `ГРІМ 0 22`, `злива 41 42` → `ЗЛИВА 42 42`. Допустимий інший код не змінюється; без опорної групи або за двох варіантів
заміни немає. Wildcard і назва, спільна з позивним, відновлення не дають. Число словами одразу після назви — цифрами, лише якщо значення
дозволене. Номер позивного — за [еталонами](learning.md#підтверджені-номери-позивних). `raw_text` не змінюється.

## Коди доби

**Розпізнавання → Коди доби.** Доба змінюється о **20:00**: коди «17.11» діють з 16.11 20:00 до 17.11 20:00. Постійні — окремим рядком.
З розпізнаного тексту автоматично не беруться. Підказка «Можливо, «48 62» — код доби?» — лише кнопкою, без автозаміни.

## Фільтри тексту

| Список | Що робить |
| --- | --- |
| Фрази-галюцинації | Відкидає фразу, що **повністю** збігається з рядком |
| Короткий шум | Відкидає короткі хибні фрагменти без позивних і команд |
| Аліаси тексту | `правильне: варіант, варіант` — до пошуку позивних |
| Аліаси позивних | `позивний: почутий варіант`; з номерами — лише перед дозволеним номером. `ясень: перший, другий` — порядкові |
| Шаблони зворотів | М’які звороти: «посилку отримаф» → «посилку отримав» |
| Шаблони фраз | Схема цілої передачі |
| Підказка Whisper | Фрази на початку підказки (до 80 символів, усі до 300); зрідка потрапляє в текст |

Початкові значення нової бази — [`shared/default_text_lists.txt`](../shared/default_text_lists.txt). Не збережуться: числа в шумі й галюцинаціях,
назви словників у них, аліас, що переписує правильну назву.

### Шаблони зворотів

Кожне слово має бути схожим, однослівні — лише в кінці фрази; числа, назви словників і звертання захищені. Вбудовано: позивний перед номером
пишеться як у словнику; «на 109» → «Набат 109», якщо номер є у єдиного позивного на «на…»; зациклення 4+ скорочуються до двох; номер,
розірваний Whisper, з’єднується, лише якщо є в словнику («Клен, 700, 73» → «Клен 773»).

### Шаблони цілих фраз

```text
{П}, {П}, я {П}, {К} звʼязку, прийом
```

`{П}` — позивний, `{Ч}` — число чи код, `{К}` — команда. Фраза, яка **повністю** пояснюється шаблоном, пишеться як у ньому: нічого не додається,
числа й «прийом/прийнято/прийняв» не змінюються, слово на місці `{П}` стає позивним лише з його дозволеним номером (без номера — збіг 80 %+).
Нові шаблони **вимкнені**: перевірте «На моїх еталонах» і вмикайте, якщо «гірше — 0».

## Налаштування без перезапуску

**Розпізнавання → Налаштування:** пауза між однаковими повідомленнями, події лише з позивними, другий шанс без підказки, код доби в підказці,
мінімальна гучність, пороги сміття, фільтр сигналів. Після перезапуску: Qwen, VAD і межі сегмента. У базі — лише змінене, «↺» повертає `config.py`.
