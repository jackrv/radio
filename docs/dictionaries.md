# 📚 Словники й фільтри тексту

[← Вікі](README.md)

Усе редагується в панелі (**Розпізнавання**), зберігається в SQLite й діє
**без перезапуску** — приймач підхоплює зміни за кілька секунд. Рядок із `#`
на початку зберігається, але не діє. Дві вкладки з одночасною правкою не
перезаписують одна одну: застаріла версія відхиляється.

## Словники

Позивні, команди й список Telegram (`/watch`) — формат як у
[`dictionaries.txt`](install.md#словники). Перевірка однакова з Mini App;
порожній словник позивних не зберігається й не застосовується.

Для команди `злива 4242` і `злива 42 42` **без двокрапки** рівнозначні:
завантажувач зберігає один код `4242`. Натомість `злива: 42 42` — список окремих
номерів `42`, а не код `4242`. Пробіли в правильному словниковому рядку самі
не відновлюють пропущену Whisper половину. За рішенням власника для точної назви
команди й однозначного коду ABAB пропущений повтор відновлюється в підсумковому
тексті та оформленні редактора. Наприклад, `злива 42` → `ЗЛИВА 42 42`.
Це не дозвіл підміняти інше число: `злива 43` не стає `ЗЛИВА 42 42`.
Якщо короткий код теж дозволено, далі вже є інша числова група або назва
збігається з позивним, відновлення не застосовується. Первинний Whisper зберігається.

Пробіли **зберігаються у словниковому рядку SQLite** й при повторному відкритті
редактора. Суцільне `4242` — лише внутрішній ключ порівняння груп, не число для
озвучення; підсумковий текст команди містить `42 42`. Перевірка збереження команд
дозволяє групи без двокрапки, максимум 9 цифр сумарно; це не перелік і не діапазон.

### Словник бере участь у виправленні тексту

В ефірі, редакторі й текстовій лабораторії застосовується одна перевірка блоків.
За точною назвою команди, повною довжиною коду та хоча б однією незміненою
словниковою групою відновлюється **єдиний** допустимий варіант:
`грім 023` → `ГРІМ 0 22`, якщо в словнику `грім 0 22`;
`злива 41 42` → `ЗЛИВА 42 42`, якщо це єдиний відповідний блок.
Допустимий інший код не змінюється. Без правильної повної групи або за двох
відповідних варіантів автозаміни немає; `грім 123` лишається почутим числом.
Wildcard і збіг назви з позивним не дають права на таке відновлення.
Для записаних окремо груп зберігається саме словникове групування; для суцільного
чотирицифрового коду — пари, для `022` — `0 22`.

Число словами одразу після відомої назви оформлюється цифрами, лише якщо його
значення дозволене: `Клен, п'ять` → `Клен 5`. Значення тут не підміняється.
Окремі контекстні помилки номера позивного потребують щонайменше трьох незалежних
одностайних еталонів архіву — див. [навчання](learning.md#підтверджені-номери-позивних).
Відновлений блок використовується і для метаданих події/Telegram; початковий
`raw_text` залишається незмінним. Застарілий словник може дати неправильний висновок,
тому нові реальні коди потрібно вносити до його застосування.

## Коди доби

**Розпізнавання → Коди доби.** Група протягом доби повторює ті самі цифрові
комбінації — їх вносить оператор. Доба змінюється о **20:00**
(`DAILY_CODES_CHANGE_HOUR`): коди «17.11» діють з 16.11 20:00 до 17.11 20:00.
Постійні коди — окремим рядком, діють щодня. З розпізнаного тексту коди
автоматично не беруться.

Редактор підказує «Можливо, «48 62» — код доби?», якщо пара цифр відрізняється
від єдиного коду однією цифрою. Лише кнопкою: автозаміна псувала б правильні
записи (коди різних днів бувають схожі).

## Фільтри тексту

**Розпізнавання → Фільтри тексту**, один список за раз:

| Список | Що робить |
| --- | --- |
| Фрази-галюцинації | Відкидає фразу, що **повністю** збігається з рядком («дякую за перегляд») |
| Короткий шум | Відкидає короткі хибні фрагменти, якщо в них немає позивних і команд |
| Аліаси тексту | `правильне: варіант, варіант` — заміна до пошуку позивних |
| Аліаси позивних | `позивний: почутий варіант`; для позивного з номерами — лише перед дозволеним номером |
| Шаблони зворотів | М’які звороти: «посилку отримаф» → «посилку отримав» |
| Шаблони фраз | Схема цілої передачі (див. нижче) |
| Підказка Whisper | Фрази на початку підказки, як їх вимовляють: «злива 42 42» |

**Початкові значення** всіх списків для нової бази — один файл
[`shared/default_text_lists.txt`](../shared/default_text_lists.txt): розділ на список,
рядки як у панелі. Він копіюється в базу один раз; далі діє лише те, що в панелі.

Не збережуться: числа в шумі й галюцинаціях, позивні й команди в них, аліас, що
переписує правильну назву, варіант із двома різними написаннями. Позивний поза
словником — лише попередження.

- **Порядкові аліаси:** `ясень: перший, другий` — «другий» означає «ясень 2»,
  якщо номер 2 є в словнику. Текст лишається «другий».
- **Кандидати з архіву** під аліасами позивних — що Whisper писав на місці
  позивного в розмічених записах. Лише підказка; «Додати» — звичайне збереження.
- **Підказка Whisper:** фраза до 80 символів, усі до 300. Зрідка потрапляє в
  текст — якщо з’являться хибні спрацювання, вимкніть рядок `#`.

### Шаблони зворотів

Схоже на зворот зі списку пишеться як у списку. Кожне слово має бути схожим,
однослівні — лише в кінці фрази. Числа, назви словників і форми звертання
захищені. Вбудовані правила (не редагуються): позивний перед номером зі
словника пишеться як у словнику; «на 109» → «Набат 109», якщо номер є в словнику
єдиного позивного на «на…»; зациклення 4+ разів скорочуються до двох (крім
«прийом», «прийнято», «прийняв»). Номер позивного, розірваний Whisper, з’єднується, лише
якщо такий номер є в словнику: «Клен, 700» → «Клен 700», «Клен, 700, 73» → «Клен 773».

### Шаблони цілих фраз

```text
{П}, {П}, я {П}, {К} звʼязку, прийом
```

`{П}` — позивний (слово й необов’язковий номер), `{Ч}` — число чи код,
`{К}` — команда зі словника. Фраза між `. ! ? ; /`, яка **повністю**
пояснюється шаблоном, пишеться як у шаблоні (`shared/phrase_patterns.py`):

- схожі слова виправляються; нічого не додається й не прибирається;
- слово на місці `{П}` стає позивним, лише якщо почутий номер є в його словнику
  (без номера — збіг 80 %+);
- числа не змінюються; «прийом», «прийнято», «прийняв» не переписуються одне
  на одне; `{К}` — лише команда або дуже схоже слово.

26 початкових шаблонів (найчастіші схеми еталонів) додано **вимкненими**.
У панелі активні шаблони показані окремо, а вимкнені згорнуті; пошук працює
в обох групах. Незбережені зміни позначені «Чернетка», а вимкнений шаблон,
увімкнений лише в поточній чернетці, — «Тимчасово увімкнено». Нові шаблони
додаються вимкненими. Перевірте чернетку
кнопкою **«Перевірити на моїх еталонах»** і зберігайте, якщо «гірше — 0».
Оцінка порівнює текст із збереженим еталоном, а не слухає аудіо; на змінених
фразах також показано, який новий шаблон вплинув на результат. На 17.11 усі 26:
4 фрази краще, 0 гірше.

## Налаштування без перезапуску

**Розпізнавання → Налаштування → Обробка без перезапуску** — групами:

| Група | Що |
| --- | --- |
| Сповіщення | пауза між однаковими повідомленнями, події лише з позивними |
| Whisper | другий шанс без підказки, код доби в підказці, мінімальна гучність |
| Відсів сміття | пороги довгого сміття й коротких невпевнених фраз |
| Фільтр сигналів | режим (вимкнено / лише оцінювати / відкидати) і три межі |

Діють за кілька секунд. **Після перезапуску** («Розпізнавання»): Qwen, VAD і межі сегмента.

Значення за замовчуванням — лише в `config.py`; у базі зберігається тільки змінене.
Змінене поле підсвічене й показує «типово …», «↺» повертає значення з `config.py`.
