# 🧹 Фільтри: що потрібне, що зайве

[← Вікі](README.md) · [Як працює розпізнавання](recognition.md) · [Канал запису](data.md#канал-запису-профіль)

Кожен фільтр відкидає запис зі своїм статусом, а ваша розмітка показує, що там було насправді.
Звідси цифри: скільки фільтр **зашкодив** і скільки **допоміг**. Рішення — лише за ними.
Усі пороги — у панелі. Там же «Фраза старша за N с» (300): стара фраза лише в архів, без події — це не якість, а сповіщення.

## 1. Порахувати

```bash
.venv/bin/python -m lab.analysis filters --profile pi-webcam            # увесь архів цього каналу
.venv/bin/python -m lab.analysis filters --profile pi-webcam --days 7   # після зміни — лише нові
```

Завжди з `--profile`: пороги підбираються під мікрофон, змішувати канали не можна.
Колонки: відкинуто, за добу, **шкода**, **користь**, не розмічено.

- Фільтри зі статусом: шкода — розмічене як мовлення, користь — шум, кімната, сигнал.
- **Шматки Whisper** (зациклення, тиша) відкидаються всередині фрази й статусу не мають; рахуються за збереженими
  шматками, також для старих записів. Для мовлення: шкода — з відкинутим шматком текст був би ближчий до еталона,
  користь — далі; рівно — не враховується. Користь зациклення — проти тексту з повним повтором; що разом із повтором
  губиться початок фрази, видно в «порожній текст».

## 2. Розмітити, якщо «мало розмітки»

Вердикт з'являється від **20** розмічених серед відкинутого. Архів → вибірка «Шум, сигнали й короткі (відсіяне програмою)»;
статус фільтра — на картці запису. Прослухати й позначити. Розмічайте підряд, а не вибірково «підозрілі», інакше частка спотвориться.
**Тихо (MIN_RMS):** нерозмічене видаляється за годину — розмічайте одразу після ефіру.

## 3. Діяти за вердиктом

| Вердикт | Умова | Що зробити |
| --- | --- | --- |
| **ВИМКНУТИ** | шкода ≥ 50 % розміченого | вимкнути (таблиця нижче), тиждень дивитися на тому ж каналі |
| **ПОСЛАБИТИ** | шкода 10–50 % | один крок порогу в бік «менше відкидати», тиждень, перерахувати `--days 7` |
| **лишити** | шкода < 10 % | не чіпати; перевірити знову після зміни мікрофона |
| **втрачене мовлення** | `empty_text` | не фільтр — зациклення Whisper; лікується в лабораторії, не порогом |

Правила кроку: **один фільтр за раз**, не частіше разу на тиждень, після кожної зміни — `--days 7` на тому ж
`--profile`. Перевірка за тиждень: Telegram не завалило (зловлене раніше тепер проходить),
а «без правок» у `lab.analysis conditions --profile …` не впав. Інакше — повернути як було.

Фільтр, що за тиждень на каналі відкинув **0** записів, нічого не робить: його можна вимикати без розмітки.

## 4. Де вимикати

Розпізнавання → **Налаштування** діє без перезапуску; «Списки» — там само, тексти фраз.

| Фільтр (статус) | Що відкидає | Вимкнути | Послабити |
| --- | --- | --- | --- |
| Тихо (`low_rms`) | сегмент тихіший за поріг, до Whisper | «Мінімальна гучність сегмента» = 0 | зменшити на 0,005 |
| Сигнал сповіщення (`notification`) | схоже на зразок звуку телефона, до Whisper | «Режим» = `shadow` (лише рахує), потім `off` | «Поріг схожості» +0,02; [деталі](signal-filter.md) |
| Довге сміття (`garbage`) | довга фраза з повторами чи надто швидка | «Перевіряти фрази від N слів» = 200 | +4 слова |
| Чорний список (`blacklist`) | фраза повністю збігається з рядком списку | очистити «Фрази-галюцинації Whisper» | прибрати рядки, що зачепили мовлення |
| Перелік назв із підказки (`dictionary_echo`) | ≥ 3 назви словника підряд за абеткою ([луна](recognition.md#луна-словника)) | «Перелік назв із підказки: від N назв підряд» = 0 | +1 назва |
| Коротке невпевнене (`low_confidence`) | до N слів з низькою впевненістю Whisper | «Коротка невпевнена фраза: до N слів» = 0 | впевненість нижче, напр. −0,7 → −0,9 |
| Короткий шум (`short_garbage`) | коротка фраза зі списку, без позивних і команд | очистити «Короткий шум» | прибрати рядки, що зачепили мовлення |
| Лише позивний (`bare_callsign`) | один позивний без номера й команд | зняти «Відкидати одиночний позивний…» | — |
| Шматок-зациклення Whisper | шматок зі стисненням > 2,4 («норок, норок…»), разом із правильним початком | «Відкидати шматок Whisper зі стисненням вище» = 0 | +0,5 |
| Шматок-тиша Whisper | шматок з no_speech > 0,6 і впевненістю < −0,8 | «Шматок-тиша: no_speech вище» = 0 | no_speech +0,1 |
| Порожній текст (`empty_text`) | Whisper нічого не дав (часто зациклення) | — | «Другий шанс» лишити ввімкненим |

Записи, що програма відсіяла, рядок списку чи поріг не видаляють: увімкнути назад можна тим самим полем.
Пороги, задані в панелі, перекривають `config.py`; повернути значення коду — поставити те саме число, що в коді.

## Коли перевіряти все заново

Після зміни мікрофона чи входу (новий `RADIO_CAPTURE_PROFILE`): пороги звукових фільтрів (тихо, сигнал)
підбирались під старий звук. Спершу вони, потім текстові. З кабелем і сигналом «канал зайнятий»
([кабель](radio-cable.md#4--канал-зайнятий-контакт-21--gpio27-етап-2)) тихо й сигнал, ймовірно, стануть зайвими — перевірити цифрами.
