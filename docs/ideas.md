# 💡 Ідеї й плани

[← Вікі](README.md)

Спільний список для людини й агентів: що запропоновано, але ще не вирішено; що відхилено
й чому; що вже зроблено. Агент читає його на початку роботи й веде далі — див. [AGENTS.md](../AGENTS.md).
Тексти й приклади — лише синтетичні (без справжніх позивних і кодів).

Пріоритет: **В** — високий (прямо про «без правок»), **С** — середній, **Н** — низький.
