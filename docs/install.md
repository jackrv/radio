# 🚀 Встановлення й перший запуск

[← Вікі](README.md)

## Що потрібно

- macOS на Apple Silicon (орієнтир — MacBook Air M4, 16 ГБ), Python 3.12, `ffmpeg`;
- бот Telegram і, для Mini App, налаштований ngrok із постійним доменом;
- інтернет — для Telegram, тунелю й першого завантаження моделей.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
cp .env.example .env
```

У `.env`:

| Змінна | Навіщо |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `TELEGRAM_CHAT_ID` | лише для реєстрації **першого** адміністратора |
| `RADIO345_NGROK_URL` | постійний HTTPS-домен ngrok (за наявності) |

Дайте терміналу дозвіл macOS на мікрофон. Токен ngrok налаштовується засобами ngrok.

## Словники

Для першого запуску всі словники готуються в одному файлі:

```bash
cp dictionaries.example.txt dictionaries.txt
```

```text
[callsigns]          # позивні й дозволені номери — хоча б один
дуб: 700 701 702
береза: 100-114
бук

[commands]           # команди й ключові слова
дощ 4242
сніг

[telegram]           # список спостереження для режиму /watch
дуб: 68
```

| Запис | Значення |
| --- | --- |
| `слово` | без номера |
| `слово: 68 69`, `слово: 300-310` | дозволені номери, діапазон |
| `слово: *` | будь-який номер |
| `слово 4242` | номер без двокрапки — цифри зливаються: `дощ 26 26` = `дощ 2626` |
| `# …` | коментар; `# @radio345-disabled: запис` — вимкнений запис |

Багатослівні назви одним записом не підтримуються.

**Імпорт.** Лаунчер сам запропонує імпортувати файл у порожню базу
(«Імпортувати словники…? [Y/N]») і після успіху видалить `dictionaries.txt` —
далі словники живуть у базі й редагуються в [панелі](panel.md). Вручну:

```bash
.venv/bin/python manage_database.py init --delete-source
```

Файл видаляється лише після commit і якщо не змінився під час імпорту. Заповнену
базу команда не перезаписує. Повернути словники у файл: `manage_database.py export`.

## Перший адміністратор

Якщо в базі немає користувачів, лаунчер перевіряє чат із `TELEGRAM_CHAT_ID`
(`getChat`), показує ім’я й ID і питає «Зареєструвати його адміністратором? [Y/N]».
Без підтвердження API не запускається. Окремо: `.venv/bin/python -m api.bootstrap_admin`.

Далі права визначає лише база: нові люди приходять через `/start` у боті
([Telegram](telegram.md#доступ-через-start)), ролі змінюються в панелі.

## Запуск

```bash
.venv/bin/python start_radio345.py     # API, ngrok, приймач і локальна панель
```

Далі — [Запуск і служби](launcher.md).
