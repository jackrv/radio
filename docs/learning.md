# 🧠 Навчання за правками

[← Вікі](README.md)

Правка фрази (Mini App, еталон в архіві) зберігається завжди. З неї виділяються **словесні правила** — заміни після розпізнавання. Ваги Whisper не змінюються.

## Підтверджені номери позивних

Номер після конкретного позивного відновлюється за **трьома незалежними одностайними** еталонами: `Клен 800` → `Клен 600`, якщо `800` не
дозволено, а `600` дозволено. Це не «найближче число»: ім'я — точне або заданий аліас; один суперечливий еталон вимикає пару; wildcard і назва,
спільна з командою, забороняють. Одна фраза рахується раз. Правила читаються з еталонів (до 10 000 останніх, кеш 30 с), лабораторія бере лише
частину `tune`; помилка читання просто вимикає підстановки.

## Що стає правилом

| | Приклади |
| --- | --- |
| ✅ **Голосує автоматично** | Коротка однозначна заміна (до 2 слів): на відому назву або схоже звичайне слово |
| ⏸️ **Чекає рішення** | Назва разом із номером, суттєво різні слова, схоже на позивний, зміна кількості слів, те саме написання лишилося поруч |
| ⛔ **Ніколи** | Числа, вставки й видалення, перестановки, один позивний на інший, слова з апострофом, 1–2 літери, одне слово виправлене по-різному |

## Коли правило діє

- **2 голоси з різних фраз** без конфліктного варіанта; повторна правка фрази замінює її голоси. Еталони мовлення всього архіву теж голосують;
  позначення шумом, сигналом чи кімнатою відкликає голоси.
- Для **позивного** — лише перед дозволеним йому номером.
- Для **звичайного слова** — лише після дозволу в панелі, лише ціле слово й ніколи перед числом.

## Розділ «Навчання»

**Розпізнавання → Навчання** показує заміни й чому кожна діє чи ні. Дозволити можна заздалегідь. За конфлікту: **якщо обидві фрази виправлені
правильно, нічого міняти не потрібно** — спільна заміна не підходить, еталони збережені; якщо помилка в джерелі — виправте запис.
Старі правки заднім числом не переробляються: збережіть фразу ще раз або натисніть **«Навчити за збереженою розміткою»** (перед цим — перевірена
копія бази; повтор зайвих голосів не додає).
