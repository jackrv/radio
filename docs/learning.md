# 🧠 Навчання за правками

[← Вікі](README.md)

Правка фрази (Mini App, еталон в архіві) зберігається завжди. З неї виділяються
**словесні правила** — заміни після розпізнавання. Ваги Whisper не змінюються.

## Що стає правилом

| | Приклади |
| --- | --- |
| ✅ **Голосує автоматично** | Коротка однозначна заміна (до 2 слів): на відому назву словника або схоже звичайне слово |
| ⏸️ **Чекає рішення оператора** | Назва разом зі своїм номером, суттєво різні слова, слово схоже на позивний, зміна кількості слів (крім «на бат» → «набат»), те саме написання лишилося невиправленим поруч |
| ⛔ **Ніколи** | Числа, вставки й видалення, перестановки, один позивний на інший, правильна назва словника, слова з апострофом, 1–2 літери, одне слово виправлене по-різному |

Текст ділиться на слова й числові групи («шістдесят вісім» = «68»); числа —
якорі, зміна номера ніколи не стає правилом.

## Коли правило діє

- **2 голоси з різних фраз** і без конфліктного варіанта. Повторна правка тієї
  самої фрази замінює її голоси, а не додає.
- Правило для **позивного** — лише перед номером, дозволеним цьому позивному.
- Правило для **звичайного слова** — лише після дозволу в панелі, лише до цілих
  слів і ніколи перед числом.

## Розділ «Навчання»

**Розпізнавання → Навчання** показує всі заміни і чому кожна діє чи ні: бракує
другої правки, чекає дозволу, конфлікт, вимкнена, заборонена. Поруч — події, з
яких вона набрала голоси. «Дозволити» можна заздалегідь — запрацює з другою
правкою. Старі правки заднім числом не переробляються: збережіть фразу ще раз.
