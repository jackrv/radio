**Стан на дату:** full large-v3-mlx, Qwen вимкнено, mono 16 кГц; 1317 speech з reference (0–30 с), ~2,19 год.
Старі turbo/Qwen-таймінги не є вимірами цієї конфігурації.

**Line-звук** (гіпотези): менше кімнатних звуків і луни, стабільніший рівень; шуми радіоканалу, обрізаний початок, цифри
лишаються. Вихід динаміка й мікрофонний вхід — не line. RMS калібрувати окремо.

**Варіанти.** 1) USB-карта → Mac, щоб ізолювати вплив джерела. 2) Pi буферизує PCM → Mac; VAD спершу на Mac, щоб
рання нарізка не сховала короткі слова. 3) Автономна Pi — менша multilingual модель; темп large-v3 не обіцяти.
Сумісність runtime, RAM і швидкість — три різні перевірки.

**Межа Pi → Mac.** Автентифікований транспорт; сесія/номер сегмента, timestamp, reconnect, ліміт диска, повтор без дублів.
ACK — лише після стійкого збереження; непідтверджене Pi не видаляє. Одна БД, один власник, не SMB/NFS. Буфер Pi —
аналог захищеного deferred, не low_rms 1 год; переповнення — рішення власника. PCM16: 32000 байт/с, 256 кбіт/с без overhead, 115,2 MB/год.

**Корпус і навчання.** Розмітка не змінює ваги Whisper. 2,19 год — підстава для пілоту, не гарантія; 2/5 год — орієнтири.
Часові train/val/test без витоку; test не для вибору правил чи checkpoint. Full fine-tuning large-v3 на 16 GB не
пропонується; CUDA/4-bit рецепти без перевірки не переносити. Кандидати: multilingual tiny (39 M), base (74 M); large — 1550 M.
Детектор команд не замінює повний текст і потребує класів «інше/не впевнений/немає мовлення»; Vosk не оцінювали.

**Не перевірено.** 50–100 нових line-еталонів, порівняння менших моделей на них, RTF/p95/ріст черги на Pi під щільним потоком.
Швидкість Mac чи чужих демонстрацій на Pi не переносити.
