# Компактна форма вибірки

[← Звіти](README.md) · [Пошук за актуальним еталоном](2026-11-21-selection-reference.md)

**21.11.2026**, commit `3f7f8b8b30ae3aa2ea1e67b54824d3edede2de65` із великим
попереднім незакоміченим деревом. Власник попросив коротке поле поряд із плашками
та зручніше введення дати/часу. Коміт/push, робочі дані й служби не змінювалися.

## Зроблено

- `local_admin/js/14-mentions.js`: однорядкове поле **190 px** стоїть після плашок
  у спільному flex-рядку; при нестачі місця переноситься. Enter/кома/крапка з комою,
  видалення плашок, збереження між сесіями та багатослівні згадки працюють як раніше.
  Окремий paste-handler зберігає поділ багаторядкової вставки, який звичайний input
  інакше втрачає. Немає другого дубльованого поля списку.
- Два компактні блоки **«Від» / «До»**, кожен має дату з календарем і окремий час
  із хвилинною точністю. Обидва поля обов'язкові й мають доступні назви.
  До API, як раніше, надходять Unix seconds з локального часу пристрою;
  це не заміна місцевого часу на UTC при введенні.
- Пресети **«Сьогодні» / «Учора» / «24 год»** лише підставляють границі.
  Пошук запускає «Знайти»; поточний snapshot самовільно не змінюється.
  Учора — між місцевими півночами з календарним переходом, 24 години — рухомий період.
- `local_admin/styles.css`: плашки й короткий input в один рядок, узгоджені
  блоки дат і часу, компактні пресети, перенос контролів без горизонтальної прокрутки.

## Перевірки

- **137 Node-тестів passed**, синтаксис JS і `git diff --check` пройшли.
  Нові змістовні регресії: багаторядкова вставка в однорядкове поле та серіалізація
  окремих дати/часу через північ у правильний 30-хвилинний API-період.
- `node tools/check_panel_ui.cjs`: справжній Chrome/API з тимчасовими SQLite/WAV;
  порожня дата блокує відправлення форми, пресет «Учора» завершується опівночі,
  «24 год» повертає діапазон для пошуку; плашка й поле розміщені поруч,
  ширина поля не більше 200 px. На **1440, 760, 390 px** немає горизонтального
  переповнення. Повний сценарій пошук → архів → розмітка та перевірка інших
  екранів також пройшли без помилок JavaScript.
- Знімки синтетичної форми: `mentions.png` і `mentions-mobile.png` у тимчасовому
  каталозі, який друкує smoke-інструмент; у Git не додаються.
- Python-код/пошукові SQL не змінювалися; повний Python-прогін не повторювали.
  Нативний календар і годинник залежать від браузера/локалі; реальний iOS не перевірений.

Власнику достатньо оновити сторінку панелі; перезапуск для цієї зміни не потрібний.
