# Вибір часу без прокручування

**Цей варіант відхилено власником.** Після уточнення він обрав
[круглий циферблат із вибором мишею](2026-11-21-analog-time-picker.md).
Нижче — історичний опис сітки, не актуальний дизайн.

[← Звіти](README.md) · [Форма вибірок](2026-11-21-selection-form.md)

**21.11.2026**, commit `3f7f8b8b30ae3aa2ea1e67b54824d3edede2de65` із попереднім
великим незакоміченим деревом. Власник показав незручний системний `input[type=time]`
із довгими прокручуваними стовпчиками. Коміт/push, робочі дані й служби не змінювалися.

## Зміни

- У «Від» / «До» системний годинник замінено полем точного часу та компактною
  панеллю: **24 години** і **12 варіантів хвилин** із кроком 5. Усе видно без прокрутки.
- Вибір години зберігає точні поточні хвилини: `09:26` → `18:26`, без округлення.
  Вибір хвилин завершує вибір і закриває панель; дата не змінюється.
- Ручне введення приймає `09:26`, `9:26`, `0926`, `926`; у запит потрапляє
  канонічне `09:26`. Після виходу з поля запис теж форматується. Numeric keyboard
  дозволяє ввести чотири цифри без пошуку двокрапки на телефоні.
- Час поза `00:00–23:59`, неповний і нечисловий ввід не пропускає форму.
  Пресет періоду скидає стару помилку, якщо підставив правильний час.
  Дата й Unix seconds, як раніше, обчислюються з місцевого часу пристрою.
- Панель закривається кнопкою «Готово», Escape, кліком поза нею, прокруткою
  або зміною розміру вікна. Після вибору хвилин фокус повертається на кнопку,
  не відкриваючи екранну клавіатуру повторно.
- Нативний Popover API виносить панель над областями з внутрішньою прокруткою;
  координати обмежені вікном, при нестачі місця вона відкривається вище кнопки.
  Є fallback для браузерів без API; залежностей і важких потоків не додано.

Файли: `local_admin/js/14-mentions.js`, `local_admin/styles.css`;
перевірки — `tests/test_mentions_state.cjs`, `tools/check_panel_ui.cjs`.

## Перевірки та обмеження

- **144 Node-тести passed**, синтаксис JS і `git diff --check` пройшли.
  Нові регресії: точні хвилини/короткий цифровий ввід, відмова від невалідного
  часу та відновлення валідності пресетом. Попередня регресія переходу через
  північ і серіалізації API-періоду лишилася.
- Chrome/API smoke на тимчасових SQLite/WAV перевіряє збереження хвилин при
  зміні години, вибір хвилин, незмінну дату, ручний ввід, невалідний час,
  закриття й усі 36 кнопок. Панель при **1440 і 390 px** повністю у вікні,
  власної прокрутки немає. Синтетичні знімки переглянуто.
- Повний сценарій вибірка → архів та перевірки редакторів також пройшов;
  реальне аудіо, Telegram, iOS і fallback старого браузера не перевірялися.
  Python/API не змінювалися, повний Python-прогін не повторювали.

Власнику достатньо оновити сторінку: натиснути годинник поряд із часом,
обрати годину й хвилини або вписати точне значення вручну. Перезапуск не потрібний.
