# Видимі вставки й чернетки в редакторах

Дата: 21.11.2026. Перевірений HEAD: `e81da99bcb51248ec5275954381b691caf256864`,
гілка `main`. У дереві вже були незакомічені зміни акустичної діагностики,
конфліктів навчання, перегляду пропозицій та відкликання Telegram-копій.
Цей етап змінює frontend, його перевірки й документацію; commit/push не виконано.

## Причина

Підсвічування вставок малювалося поверх старого textarea, який новий рядковий
редактор приховує. Видимий адаптер будував модель уже після вставлення та
приймав додані рядки за збережені. Toast повідомляв про додавання, але не
показував, де саме зміна. Відтворено синтетично в браузері й регресійних тестах.

## Виконано

- `local_admin/js/07-recognition.js`: спільний редактор отримує справжній стан
  до вставлення/перегляду. Нові та змінені рядки жовті з «Чернетка»;
  ввімкнений для перевірки шаблон — «Тимчасово увімкнено». Позначка не зникає
  при пошуку чи зміні перемикача; збереження/скасування прибирає її.
- Нові аліаси та номери в наявному рядку виділяються саме як доданий фрагмент.
  Зіставлення збережених рядків за змістом, потім назвою дозволяє додавати,
  розділяти й пересувати рядки без хибних позначок у решті списку.
  Індекси побудовано через Map, без повного пошуку baseline для кожного рядка.
- Перехід прокручує справжній редактор, фокусує поле, розкриває вимкнені рядки
  за потреби. Виконується після відновлення навігації; відкладена дія не
  забирає фокус, якщо людина вже перейшла в інший розділ.
- Повторна пропозиція підсвічує наявний рядок синім із «Вже збережено», без
  дубля й штучної незбереженої зміни. Кнопки кандидатів шуму й аліасів,
  що зберігають відразу, показують синій «Щойно збережено».
- Швидко доданий з архіву позивний підсвічується при відкритті словника;
  чинна незбережена словникова чернетка не перезаписується.
- `local_admin/styles.css`: колір справжніх рядків та компактна висота.
  Раніше CSS grid розтягував кілька рядків на всю висоту робочої області.
- В `AGENTS.md` записана пряма вимога власника: будь-які такі підставлення
  мають бути видимими; одного toast або підсвічування прихованого поля недостатньо.

## Застосування

Оновити сторінку панелі: JS/CSS читаються з диска з `no-store`, перезапуск
служб для цього frontend-етапу не потрібний. Перегляд пропозиції як і раніше
не доводить її безпечність: оператор перевіряє чернетку й явно зберігає.
Наступним агентам зберігати цю видимість для нових способів вставлення.
