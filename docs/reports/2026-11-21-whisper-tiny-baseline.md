## Виконано й виміряно

Завантажено мультимовну [mlx-community/whisper-tiny](https://huggingface.co/mlx-community/whisper-tiny),
ревізія `78c52ab98ca87f570bc57ad852e15ef7060f9f76`, ваги 74418182 байти.
Модель у `.local-models/whisper-tiny`; каталог додано до `.gitignore`.
Нових Python-бібліотек не встановлювали. Робочу модель й пороги не змінювали;
ваги не навчали.

Зафіксовано 162 наявні WAV із часового holdout: 120 speech, 8 noise,
14 notification, 20 room; 17,93 хв аудіо, кожен запис до 30 с, seed 345.
Еталони, індекс, словники й runtime settings збережено SQLite-знімками;
WAV мають SHA-256. Приймальну й архівну розмітку тест не редагує.

Параметри чинної лабораторії: pipeline, llm off, uk, prompt receiver,
код доби latest, retry on, normalize on, MIN_RMS 0,02, температура 0/0,2/0,4.
Обидві моделі прогріваються; процеси послідовні після зупинки приймача.

Tiny завершила 162/162 без помилок за 172,5 с разом із підготовкою/прогрівом.
Після текстової обробки:

- без правок **0/120**;
- пропущене мовлення **28/120**;
- WER **111,96 %**: вставки можуть підняти WER вище 100 %;
- хибний текст **2/22** на шумі/сигналах і **11/20** на кімнаті.

Поточна tiny не придатна для заміни робочої моделі. Це результат без
донавчання з поточною підказкою, а не доказ неможливості поліпшення.

## Парний результат після продовження

Після нового доручення власника виконано лише решту **63** записів large-v3.
Разом **162/162** для кожної моделі, без помилок і без RMS-відсіву.
Перевірено рівність ідентифікаторів/WAV SHA-256, fingerprint словників, підказки,
runtime/декодування та правил номерів. Дві частини large мають однакові версії
рушія/ревізію моделі; об'єднані без перезапису початкових частин.

| Показник | Tiny | Поточний large-v3 |
| --- | ---: | ---: |
| Без правок після pipeline | 0/120 (0 %) | 14/120 (11,67 %) |
| Пропущене мовлення після pipeline | 28/120 | 2/120 |
| WER після pipeline | 111,96 % | 62,18 % |
| Числа повністю збігаються після pipeline | 0/116 | 33/116 |
| Хибний текст на noise/notification після pipeline | 2/22 | 4/22 |
| Хибний текст на room після pipeline | 11/20 | 15/20 |
| Whisper: середнє / p95 / максимум | 1,044 / 2,636 / 3,932 с | 3,103 / 11,066 / 24,658 с |
| Обробка всіх записів без прогріву | 169,80 с | 503,85 с |
| Сумарний RTF: обробка / аудіо | 0,158 | 0,468 |
| RTF одного запису: p95 / максимум | 0,529 / 0,643 | 1,616 / 6,568 |

До словесної обробки й фільтрів, але після `extract_text` Whisper:
tiny — 0 точних / 26 пропусків / WER 112,72 %; large — 11 точних /
1 пропуск / WER 66,38 %. Хибний raw-текст на noise/notification: 10/22 проти 21/22,
на room: 13/20 проти 20/20. Це не непрофільтрований повний декодерний вихід.
За кількістю помилок слів після pipeline tiny краща на 8 фразах, однакова на 17,
гірша на 95. Головний показник — частка фраз без правок.

Виграш tiny за часом обробки — близько **2,97 раза**, а не співвідношення параметрів.
Вона рідше вигадує текст на негативних прикладах, але часто не розбирає справжню
мову. Без донавчання не замінювати нею large. Результат майбутнього fine-tuning
не встановлено. Large теж має лише 11,67 % без правок на цьому зрізі.
Його сумарний RTF нижчий за 1, але довгі хвости й RTF окремих записів понад 1
можуть створювати чергу у щільному ефірі; це не вимір живої затримки.

Завершений контроль — приватний `large-combined/` у каталозі експерименту.
`aggregate.json` містить підсумки, `params.json` — посилання на обидві частини.
Два прогріви large разом 7,64 с не включені до 503,85 с обробки.
Фіксований порядок, два вікна й відсутність контролю температури обмежують
узагальнення швидкості; Raspberry Pi не тестували.

## Історія зупинки й відновлення приймача

Контрольний large-v3 зупинено SIGINT на **99/162** записах заради запису ефіру.
На тому етапі парного результату ще не було. За новим дорученням виконано решту
записів. Код початкової лабораторії -2 — запитана зупинка, не збій MLX;
продовження завершилося з кодом 0.

Після обох вікон через `--receiver-start` приймач повернуто: flock утримується, порти
8765/4040/8766 зайняті службами, heartbeat **listening** віком **0,7 с**.
Lock-файли не видаляли, панель/API/ngrok не перезапускали.
Після завершення продовження readonly heartbeat повторно підтвердив listening,
вік 0,6 с. Подальшого автоматичного запуску тестів немає.

Приватні manifest, frozen DB, provenance та журнали —
`.local-experiments/tiny-benchmark-2026-11-21/`; завершений tiny і частковий
large також у звичайних каталогах прогонів. Аудіо/тексти не публікувати.
