# Кінцевий «прийнято, прийом»: контекстні правила R1–R3

[← Звіти](README.md) · 22.11.2026 · HEAD `97aa396`, dirty · readonly, без ASR

**Привід.** 535 із 1438 еталонів мовлення так закінчуються; raw має це у 35, після обробки — у 113. Кінці raw у них:
«прийом прийом» 84, порожньо 26, «прийом <слово>» 65, «<щось> прийом» 263. Серед фраз з однією помилкою ≈30 із 126.

**Правила** (`fix_closing_turn` у `core/template_text.py`, після всіх інших; лише кінець тексту; вимикач `CLOSING_TURN`;
raw незмінний):
- R1 «… прийом <випадкове>» → «… прийнято, прийом»
- R2 «… прийом прийом [прийом…]» → «… прийнято, прийом» (`fix_double_over` у середині — як раніше)
- R3 «… <число|позивний> <випадкове> прийом» → «… <число|позивний> прийнято, прийом»

«Випадкове» — поза зворотами, службовими словами, назвами словників, звертаннями, числівниками; число, позивний і
«прийом/прийнято/прийняв/я» — не випадкові.

**Умови прийняття ключа:** користь у ≥3 різних 20-хв блоках, 0 шкоди, 0 збігів на noise/notification/room (`unclear` не
враховано; нейтральне — не шкода). Вивчено на train, обрано на val, holdout — один раз.
**Відхилено:** `<N> прийом` → вставка (+29/−107), `<?> прийом` без контексту (+39/−68); решта ключів рідкісні або без сенсу.

**Межі.** Архівні final не переписуються. «Прийняв, прийом» стає «прийнято» (нейтрально; розрізнення відкрите).
Пропущене «прийнято» після числа не виправляється: справжні виклики такі самі. «Випадкове» залежить від словників/зворотів.
