Гілки `pi-hub` і `layout` злито в `main`; останній коміт цього етапу — b92fb1b.

## Рішення власника

- Один репозиторій (і Mini App), один код на Mac і Pi; окремі процеси, профілі пристроїв.
- «Дім» (база, бот, Mini App, ефір) переноситься кнопкою, бази не зливаються. Керування — лише Mac → Pi (SSH).
- Конфлікти (бот, тунель, база зайняті) перевіряються самі; повторних спроб немає. Копії баз Pi — за бажанням, до 3.
- Старий лаунчер, `radio.py`, режим «лише запис», `pause_gate`, claudeSearch видалено.

## Як улаштовано

- `server/` (node, asr з ботом, panel, api, tunnel), `worker/` (Whisper), `lab/`, `shared/`; тест забороняє залежності між ними.
- Фраза: ефір → файл черги → asr → `remote_recognizer` (HTTP 8347) → база; Mac недоступний або фраза старша 300 с → `deferred`, без подій.
- Відібрані тексти йдуть в ефір файлами (`phrase_feed`, останні 30, номери й сеанс переживають перезапуск); база ефіру не потрібна.
- Замки: `model`, `owner`, `worker`, `lab`; модель лабораторії віддає вузол (`model_pause`, строк до 4 год).
- Дані — `.local-data/` через `shared/paths.place`; звук — файл машини, не база. Код конфлікту 75: r345 і systemd не перезапускають.
- Перенесення: `server/home_move.py` (знімок → звірка → копія старої бази → запис через Backup API → позначки → запуск; збій повертає джерело).

## Оновлення й служба на Mac (24.11, після 3d0dcff)

- `./r345 update [mac|pi]` і кнопки панелі: Mac — лише ff із GitHub з чистого дерева, перевірка імпорту, повернення при збої; Pi — коміт Mac.
  Одна зміна за раз (`shared/busy.py`). Справжнього оновлення Mac не було: новішого коду на GitHub немає.
- `./r345 service on|off|status`: launchd тримає `r345 up`; з `~/Documents` відмовляє. Перевірено справжнім launchd на тимчасовій копії з
  процесами-заглушками: запуск, повернення після kill -9, штатний `stop` не піднімається, слідів немає. Мікрофон із launchd (Python з Homebrew) — RMS 742.
  Не перевірено: повна система службою, Whisper, перезавантаження Mac. Власник переносити проєкт поки не планує.

## Уроки

- Через launchd немає доступу до `~/Documents` (код 126): агенти працюють зі знімків у `~/Library`.
- Сервер фраз нумерував із 1 після перезапуску, і застосунок пропускав нові: додано `session`.
- Видалення `radio.py` забрало запис діагностики й бота на Mac: перед видаленням звіряти, що ще робив модуль.
- Повернення з Pi без карти не піднімало ефір: виправлено.
