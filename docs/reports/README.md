Старіші звіти (25) — в [архіві покажчика](archive.md); у покажчику лишайте ~12 найновіших.

Для нового звіту використовуйте назву `YYYY-MM-DD-topic.md`. Зазначайте перевірений
commit, незакомічені зміни, докази, обмеження, зроблене, залишок роботи й перевірки.
Додавайте посилання на попередній звіт, якщо продовжуєте його роботу. Плани й рішення
людини узгоджуйте з `../ideas.md`. Приватні матеріали сюди не копіюйте.
