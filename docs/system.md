# 🧭 Як усе влаштовано

[← Вікі](README.md)

| Пристрій | Що робить |
| --- | --- |
| **Pi** | дім системи: ефір (з USB-картою), база, бот, панель, API Mini App |
| **Mac** | Whisper (вузол), лабораторія, розробка |
| **iPhone** | «Наживо», «Відібрані», список фраз, передача |

Шлях фрази: рація → ефір (Pi) → черга → Whisper (Mac) → розбір тексту й база (Pi) → Telegram, панель, iPhone.

| Немає | Що працює далі |
| --- | --- |
| Mac | ефір, панель, бот; нові фрази чекають у черзі й пізніше потрапляють в архів **без** сповіщень |
| Pi | застосунок показує останні 30 фраз; нового ефіру немає |
| USB-карти в Pi | панель, бот, Mini App; ефіру немає |

Усе між пристроями йде через Tailscale. Бот і тунель Mini App працюють лише на **одному** пристрої. Бази Mac і Pi не синхронізуються.

## Режими

Панель на Mac (запасна, `./r345 restart panel`): «Система» → «Пристрої». Кнопка сама вмикає потрібні служби й зупиняє зайві; панелі не чіпає.

| Режим | Mac | Pi |
| --- | --- | --- |
| **Працює Pi** | Whisper | ефір, бот, API |
| **Усе на Mac** | Whisper, ефір, бот, API | — |
| **Вимкнено** | — | — |

Панель Pi керує своїми службами й звуком (зупинка діє до перезавантаження Pi); дозвіл — один раз на Pi `sudo sh deploy/hub/control.sh`.
Тунель Mini App вмикають окремо, за потреби. Якщо дім на іншому пристрої, режим спершу запропонує перенести його.
`./r345 up` на Mac сам зважає на дім: коли він на Pi, стартує лише Whisper. Те саме з консолі: `./r345 home pi | mac | off`.

## Перенести дім

Зупинити служби — не перенести: база лишається за старим домом, тож бот на іншому пристрої не стартує («дім на Mac»).

На Mac: `./r345 home pi` / `home mac` (або панель Mac → вибір режиму). Переїжджають база, індекс архіву (тексти й розмітка), бот, Mini App, ефір;
з Pi на Mac — ще й записаний звук (з Mac на Pi — ні). Стара база цілі лишається в `.local-data/backups/before-move-*`. Збій повертає все назад.
На іншому пристрої бот і API не запускаються, панель — лише для читання.
