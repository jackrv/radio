# 💬 Telegram і Mini App

[← Вікі](README.md)

## Сповіщення

Кожен активний користувач отримує в особистий чат із ботом голосове OGG/Opus з
текстом — за **власним** режимом (загального режиму немає):

| Команда | Режим | Кому |
| --- | --- | --- |
| `/all` | усі фрази | лише адміністратор (його типовий) |
| `/commands` | команди й позивні | усім (типовий для нових) |
| `/watch` | лише список спостереження `[telegram]` | усім |
| `/off` | вимкнено | усім |

Режим змінюється командою, у Mini App («Головна») або адміністратором у панелі.
Права й режим перевіряються ще раз перед надсиланням із черги; якщо базу прав не
прочитано — розсилки немає.

**Шапка повідомлення:** «Подія» (збіг зі списком `[telegram]`), «Команди» — як
вимовляють («злива 42 42»), «Кому / Від». Аудіо завантажується один раз і
використовується для всіх; заблокованих бот пропускає; при збої — текст.

**Кнопки:** `admin` і `editor` — «Виправити в редакторі» й видалення; `viewer` —
лише видалення. Видалення в адміністратора приховує фразу в журналі для всіх, в
інших — лише власну копію.

## Доступ через `/start`

1. Новий користувач надсилає `/start` боту.
2. Активні адміністратори отримують картку з іменем, @username і ID та кнопками
   **👁 Спостерігач**, **✏️ Редактор**, **✖️ Відхилити**.
3. Після рішення картки зникають в усіх адміністраторів, користувач отримує
   кнопку Mini App. Роль `admin` так не видається — лише в панелі.

Повторний `/start` не дублює заявку (через 24 год без рішення картку надіслано
знову); після відмови — новий запит через 24 год; одночасно до 20 заявок.
Службові картки оновлюються на місці, команди бота прибираються з чату.

## Mini App

Статичний HTML/CSS/JS ([`miniapp/`](../miniapp/)), публікується GitHub Pages і
працює з локальним API через ngrok. Кожен запит перевіряє підпис і строк
Telegram `initData` та актуальні права в SQLite.

| Роль | Може |
| --- | --- |
| `viewer` | лише стан ефіру |
| `editor` | журнал, аудіо, виправлення фраз, власні сповіщення |
| `admin` | ще пауза приймача на 5–60 хв |

Словники, навчання, користувачі й налаштування — **лише в локальній панелі**,
через ngrok вони не відкриваються.

- **Головна** — стан приймача, свій режим одним дотиком, пауза (admin).
- **Виправлення** — пошук, по 10 фраз, аудіо й редактор з підказками оформлення.
  Текст і навчання зберігаються однією транзакцією.
- Якщо сервіс недоступний — екран «Сервіс Radio 345 недоступний» з автоповтором
  кожні 10 с; незбережений текст редактора не втрачається.

`db:<id>` — подія SQLite, `mem:<token>` — тимчасова фраза (24 год, до 200).

## Правки й копії в чатах

Збережена правка ставить оновлення **всіх копій** у стійку чергу SQLite: підпис
замінюється з позначкою «✏️ Виправлено оператором», шапка перераховується.
Черга переживає перезапуски й обриви мережі (до 5 копій за 5-секундний цикл,
`retry_after`, до 8 спроб). Копії без збереженого `message_id` (давні) оновити
неможливо. Підпис обрізається до 1024 символів, текст — до 4096.

## Видалення в усіх

**Аудіоархів → картка надісланого запису → «🗑 Видалити в Telegram у всіх (N)».**
Фраза одразу зникає з журналу й Mini App, копії бот видаляє за кілька секунд
(якщо приймач зупинено — після запуску). Telegram дозволяє ботові видаляти свої
повідомлення лише **48 годин**, тому кнопка є лише для свіжих записів.
Ручне видалення засобами Telegram не синхронізується.

## Перевірка й публікація

```bash
node --test tests/*.cjs
```

Після змін API перезапустіть служби; після змін лише інтерфейсу — достатньо
публікації Pages і повторного відкриття Mini App. Мобільний вигляд, клавіатуру
й аудіо перевіряйте на телефоні.
