# Radio 345 Mini App · UI 0.1

Первый адаптивный интерфейс управления Radio 345. HTML, CSS и JavaScript без сборки и npm.

## Локальный просмотр

Из папки, содержащей `index.html`:

```bash
python -m http.server 8080 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8080/` на этом же компьютере.

## Что работает

- Переключение разделов интерфейса.
- Демонстрационный редактор с предзаполненным текстом, возвращение образца.
- Адаптивное меню для телефона и десктопа.
- Telegram WebApp SDK и определение факта запуска внутри Telegram.

## Что сознательно не работает

- Запросы к API или SQLite (их в этой версии вообще нет).
- Показ живого состояния радиоприёмника и подписок.
- Отправка исправлений, приостановка аудио, включение тишины, редактирование словарей и пользователей.

Кнопки управления отключены, пока не добавлены защищённый HTTPS API и проверка прав. Не используйте `initDataUnsafe` для серверной авторизации. **Не публикуйте** `.env`, SQLite, секреты и персональные записи на GitHub Pages.

## GitHub Pages

В отдельном репозитории разместить `index.html`, `styles.css`, `app.js` в корне и выбрать в Settings → Pages публикацию из ветки `main`, каталога `/ (root)`.

Для полноценного запуска Telegram Mini App нужно зарегистрировать HTTPS URL в настройках бота и подключить защищённый API.
