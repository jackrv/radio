# Radio 345 Mini App

Компактна панель на HTML, CSS і JavaScript без npm-збирання. Статичні ресурси
публікує `.github/workflows/miniapp-pages.yml`. Дані зберігаються в локальній SQLite,
доступ до FastAPI проходить через HTTPS-тунель. Інтерфейс українською мовою.

## Розділи

- **Головна:** heartbeat приймача, кількість подій, активних правил і рядків
  словників, час останньої події та Telegram ID оператора.
- **Виправлення:** пошук, по 10 фраз на сторінку, події `db:` та тимчасові `mem:`.
  Вибрана фраза відкривається в окремому редакторі. Початковий текст розгортається,
  поле виправлення зростає без внутрішньої прокрутки. Текст і навчання зберігаються
  в одній транзакції. Повторна правка замінює голоси джерела, не додаючи зайвих.
- **Аудіо:** плеєр поруч із фразою та в редакторі відтворює початковий запис,
  навіть після виправлення тексту. Потрібна збережена прив’язка Telegram `file_id`.
  Старі записи без прив’язки не відновлюються автоматично. API перевіряє права,
  строк і стан фрази; токен та `file_id` браузеру не передаються. OGG до 2 МБ
  завантажується в пам’ять без локального архіву. Для пристрою без підтримки OGG
  залишається початкове голосове повідомлення в Telegram.
- **Словники:** додавання, редагування, вимкнення й видалення рядків. Нова строка
  підсвічується, отримує фокус і стає видимою. Зміни застосовуються після
  перезапуску приймача. Не можна залишити його без увімкнених позивних.
- **Навчені заміни:** пошук, кількість підтверджень, статус і вимкнення/повторне
  ввімкнення зі штатними перевірками. Вручну голоси не додаються.
- **Налаштування:** сповіщення застосовуються одразу; Qwen, VAD і сегментація —
  після перезапуску. Форма показує збережені значення для наступного запуску.
- **Користувачі:** ролі, власні назви й вимкнення доступу. Ім’я Telegram оновлюється
  після перевіреного входу користувача; власна назва адміністратора має пріоритет.
  Останнього активного адміністратора не можна вимкнути або понизити.

## Права й взаємодія

`viewer` переглядає журнал і словники. `editor` також редагує фрази, словники та
стан правил. `admin` додатково керує налаштуваннями, паузою й користувачами.
Кожний API-запит перевіряє підпис, строк Telegram `initData` й актуальні права.
Клієнтська роль лише визначає вигляд кнопок. Для керування версія даних і права
перевіряються повторно всередині транзакції SQLite.

Спільний HTTP-клієнт має таймаут 15 секунд. Скасування запиту не гарантує відкату
вже розпочатої серверної транзакції: при невизначеності оновіть дані перед повтором.
Конфлікт не перезаписує чужу правку. Дані API не кешуються, текст вставляється
через `textContent`/`value`. У браузері зберігається лише вибір автозакриття.

Для `mem:` діє максимум 24 години та 200 фраз; редагування не продовжує строк.
Видалення кнопкою бота приховує фразу та доступ до редактора, але зберігає подію
й навчання. Явна відмова Telegram не приховує фразу. При невизначеному мережевому
результаті зберігається намір видалення до повторної обробки. Звичайне ручне
видалення в Telegram і видалення до встановлення цього механізму не синхронізуються.

Під час введення є кнопка **«Сховати клавіатуру»** біля нижнього краю видимої
області. Також працюють натискання на фон і Escape. Використовується Telegram
`hideKeyboard` за наявності підтримки та зняття фокуса як резервний спосіб.
На мобільному пристрої нижнє меню приховується під час введення.

## Перевірка й публікація

```bash
venv/bin/python -m pytest -q
node --test tests/miniapp.test.cjs
```

Тест ресурсів перевіряє всі JS/CSS у workflow Pages та порядок завантаження
спільного клієнта. Node-тести використовують модель DOM, а не реальний телефон.
Перед публікацією змін API перезапустіть локальні служби; для змін лише інтерфейсу
перезапуск служб не потрібен. Після публікації закрийте старе вікно Mini App
і відкрийте його знову.

На телефоні перевірте: переходи між розділами, пошук і сторінки журналу,
редактор `db:`/`mem:`, аудіо до й після виправлення, автозакриття, новий рядок
довгого словника, закриття клавіатури без втрати тексту та обмеження ролей.
Конфлікти й помилки SQLite перевіряються автоматично на тимчасових базах.
Не змінюйте чутливість VAD робочого ефіру лише заради тестування форми.

`--local-miniapp` запускателя відкриває локальний перегляд. Без авторизації Telegram
панель не отримує робочі дані; localhost не входить до дозволених CORS-origin API.
